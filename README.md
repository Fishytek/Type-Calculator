# 🧮 Advanced Multi-Type Calculator
> Мощный калькулятор на базе **Qt 6.9.1**, поддерживающий динамическую смену типов данных и работу с рациональными числами.


## 🌟 Особенности
Проект предлагает гибкость вычислений за счет строгого управления типами данных. Вы можете переключать контекст вычислений в зависимости от ваших задач.

- **🎯 Гибкая типизация**: Выбирайте нужный тип данных прямо во время работы.
- **🛡 Безопасность**: Использование системных типов и контроль переполнений.
- **🧩 Rational Type**: Уникальная поддержка дробных выражений (числитель/знаменатель) для сохранения абсолютной точности.
- **💾 Memory Access**: Полноценная работа с регистрами памяти (Save/Clear).

---

## 🔢 Поддерживаемые типы

| Группа | Тип данных | Описание |
| :--- | :--- | :--- |
| **Float** | `double`, `float` | Стандартные числа с плавающей запятой |
| **Integer** | `int`, `int64_t`, `uint8_t` | Целочисленные значения разной разрядности |
| **System** | `size_t` | Системный беззнаковый тип |
| **Special** | **`Rational`** | Дробные выражения с сохранением числителя и знаменателя |
