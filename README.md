<b>Калькулятор</b>

Калькулятор сделанный с помощью Qt 6.9.1
Данный калькулятор имеет выбор типов данных для которых он высчитывает значение
Вот все типы:
double
float
uint8_t
int
int64_t
size_t
Rational(Отдельный тип под робные выражения с дробной чертой)
Калькулятор имеет функции сохранения и очистки памяти
